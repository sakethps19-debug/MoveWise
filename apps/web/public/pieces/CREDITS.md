# Piece art credits

These 12 SVGs are the "Cburnett" chess piece set, originally created by
Colin M.L. Burnett and released under the Creative Commons
Attribution-ShareAlike 3.0 Unported license (CC BY-SA 3.0):
https://creativecommons.org/licenses/by-sa/3.0/deed.en

It's the same set used as Lichess's default board theme. Used here
unmodified. Extracted from the `react-chess-pieces` npm package
(ISC-licensed wrapper code, bundling this artwork), not redrawn.
